# 隐私政策

**生效日期:2026 年 8 月 17 日**

本隐私政策适用于「做个好人AI股票分析系统」(以下简称「本应用」,Android 包名
`com.stockoperatoragent.app`,含对应的 Web 版与桌面版)。本应用是一款基于真实市场
数据与多智能体协作的股票分析决策工具。

本应用**不注册账号、不收集个人身份信息、不包含广告、不集成任何第三方统计分析
或广告 SDK**,也没有由开发者运营的后端服务器。您在使用本应用时提供的全部信息
均保存在您的设备本地,由您自行掌控。

---

## 1. 我们收集的信息

### 1.1 您主动提供的信息

- **API 密钥**:为使用 AI 分析功能,您需要在应用设置中填写第三方服务的密钥,
  包括:大语言模型服务(OpenAI 兼容接口)的 `LLM_API_KEY`、模型名与接口地址;
  可选的通达信(TDX)行情服务密钥 `TDX_API_KEY`;可选的亿信 Fin 金融数据服务
  密钥 `BILLIONS_API_KEY`。
  - 这些密钥**仅保存在您的设备本地**(Web 版存于浏览器 localStorage/IndexedDB,
    Android 版存于应用私有沙盒,桌面版存于本机应用数据目录),**不会**上传至
    开发者服务器,也不会在日志中记录。
- **股票代码**:您主动输入并请求分析的股票代码(如 `600036`)。

### 1.2 我们自动收集的信息

- **本地日志**:应用在设备本地记录运行日志(含分析过程文本),用于排查问题。
  日志仅存于设备本地,不自动上传。

### 1.3 我们不收集的信息

本应用**不**收集:姓名、身份证号、手机号、邮箱、通讯录、短信、通话记录、
精确定位、相册、麦克风、摄像头等任何个人身份信息;不进行任何形式的用户行为
追踪或画像;不采集设备广告标识符(IDFA/GAID)。

---

## 2. 我们如何使用信息

- **API 密钥**:仅用于在您发起分析时,向您指定的第三方服务(见第 3 节)发起
  经您授权的请求,以完成 AI 分析。
- **股票代码与市场数据**:仅用于完成您请求的股票分析,包括向行情服务拉取该
  股票的行情、财务与新闻数据。
- **本地日志**:仅用于本地问题排查;您可随时清除。

我们**不会**将上述信息用于分析之外的任何用途,不会用于定向广告,不会出售或
出租任何数据。

---

## 3. 信息的共享与第三方

本应用**不向任何第三方出售、出租或共享您的个人信息**。仅在您主动发起分析时,
为完成您请求的功能,下列请求会携带必要数据直连第三方服务(均为**您自行配置
或授权**的服务,数据不经开发者中转):

| 第三方 | 用途 | 传输的数据 |
|---|---|---|
| 您指定的大语言模型服务商(OpenAI 兼容,如 DeepSeek、OpenCode Zen、本地 vLLM/Ollama 网关)| AI 分析推理 | 分析提示词(含股票代码与相关行情文本)、您的 API 密钥(用于鉴权)|
| 通达信(TDX)行情服务器 | 行情/财务/技术指标采集 | 股票代码、行情请求 |
| 亿信 Fin(可选,配置密钥后启用) | 公告/研报/新闻检索与金融问数 | 股票代码、检索词 |
| 联网搜索服务(Tavily / DuckDuckGo)| 信息面素材检索 | 检索词(含股票代码)|

> 请注意:您选择接入的第三方服务(尤其自行指定的大语言模型服务商)有各自的
> 隐私政策与数据处理方式,建议您在使用前了解其条款。本应用对第三方服务的数据
> 处理行为不承担责任。

---

## 4. 数据存储与安全

- 所有数据(密钥、设置、历史分析结果、日志)均存储在**您的设备本地**,本应用
  无自有服务器,数据不会离开您的设备,除非您主动发起第 3 节所述的分析请求。
- 我们建议您妥善保管 API 密钥;密钥泄露风险与您对密钥的使用环境(如共享设备、
  公共网络)相关。

---

## 5. 权限说明

Android 版申请以下权限,均仅用于核心功能:

- **通知权限(POST_NOTIFICATIONS)**:用于在分析任务进行时向您展示进度通知。
- **前台服务(FOREGROUND_SERVICE / FOREGROUND_SERVICE_DATA_SYNC)**:用于在
  分析任务进行中维持后台数据同步任务。

我们不会申请定位、通讯录、短信、通话、相机、麦克风等任何敏感权限。

---

## 6. 您的权利

您对本应用中的数据拥有完全的控制权:

- **删除数据**:在应用设置中清除对应数据,或卸载应用,即可删除全部本地数据
  (含 API 密钥、历史分析、日志)。
- **撤销授权**:随时在应用设置中修改或删除 API 密钥,停止相应第三方服务的使用。
- **不提供数据**:您可以选择不配置任何密钥(应用将以演示模式运行),或关闭
  任一可选数据源。

由于本应用不收集个人信息、无自有服务器,您无需向我们提交数据删除请求即可
完全掌控数据;您随时可通过卸载应用清除所有本地数据。

---

## 7. 儿童隐私

本应用面向成年用户,不面向儿童,不包含儿童定向内容,不收集儿童个人信息。
本应用不要求提供年龄信息,也不提供需年龄验证的功能。

---

## 8. 政策变更

本政策可能随应用功能或法律法规要求更新。更新后将在本页面发布新版本并更新
「生效日期」。重大变更时,我们会在应用内显著位置提示。
